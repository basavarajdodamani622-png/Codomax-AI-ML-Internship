# Module 06: AI-Powered Smart Career Recommendation System

## Project Overview
This project demonstrates a machine learning classification model that predicts a career category based on six example skill ratings.

## Objectives
- Prepare and explore a career recommendation dataset.
- Train a Decision Tree classification model.
- Evaluate model performance using accuracy, precision, recall, and F1-score.
- Visualize career categories and example skill ratings.
- Generate a career category prediction from user-provided skill ratings.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Dataset
The project uses a **synthetic dataset of 120 records**, with 20 records for each of six career categories:
- AI/ML Engineer
- Data Scientist
- Web Developer
- Full Stack Developer
- UI/UX Designer
- Data Analyst

The dataset is artificially generated from predefined example skill profiles. It is for educational demonstration and does not represent real career-market data.

## Model
- Algorithm: Decision Tree Classifier
- Input features: Python, Machine Learning, Web Development, Communication, Problem Solving, Creativity
- Target: Career category
- Train-test split: 80% training and 20% testing
- Random state: 42

## Evaluation Results
- Test records: 24
- Accuracy: 79.17%

The evaluation is based on a small synthetic dataset. This result should not be interpreted as evidence of real-world career recommendation accuracy.

## Project Files
- `Codomax_Module_06_Student_Performance_Prediction.ipynb` — Google Colab notebook containing the project code
- `career_model_results.csv` — Model accuracy results

## Conclusion
This project demonstrates a basic machine learning workflow, from dataset preparation and model training to evaluation, visualization, and career-category prediction. The predictions are educational examples, not professional career guidance.
