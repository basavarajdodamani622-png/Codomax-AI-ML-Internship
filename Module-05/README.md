# Module 05: AI-Powered Iris Flower Predictor

## Project Overview
This project uses machine learning to predict Iris flower species from four measurements.

## Technologies
- Python
- Pandas
- Scikit-learn
- Decision Tree Classifier
- Google Colab

## Dataset
The Iris dataset contains 150 records, four input features, and three flower species.

## Model Results
- Training records: 120
- Testing records: 30
- Test accuracy: 93.33%

## Flower Species
- Setosa
- Versicolor
- Virginica

## Conclusion
This project demonstrates data preparation, machine learning model training, evaluation, and flower species prediction using Python.
