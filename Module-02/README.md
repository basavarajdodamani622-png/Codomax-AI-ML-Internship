# Module 02: Python Mini Project

## Student Grade Calculator

### Project Overview
A beginner-friendly Python project that calculates a student's total marks, average marks, and grade for three subjects.

### Features
- Accepts the student's name.
- Takes marks for three subjects.
- Validates marks between 0 and 100.
- Rejects non-numeric inputs.
- Calculates total and average marks.
- Assigns a grade based on the average.

### Python Concepts Used
- Variables and data types
- User input and output
- Loops
- Lists
- Conditional statements
- Exception handling
- Arithmetic operations

### How to Run
Run the following command in a terminal:

```bash
python student_grade_calculator.py
```

### Testing
The program was tested with valid marks and invalid text inputs. It correctly calculates results and requests valid input when needed.
