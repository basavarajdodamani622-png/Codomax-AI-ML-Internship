# Module 03: Data Analysis & Visualization

## Project Overview
This project explores student performance data using Python, Pandas, NumPy, and Matplotlib.

## Dataset
The dataset contains 10 students and 4 columns:
- Student
- Study_Hours
- Attendance
- Marks

## Tasks Completed
- Imported Pandas, NumPy, and Matplotlib.
- Created and explored a dataset using Pandas.
- Checked data types, missing values, and duplicate rows.
- Calculated average study hours, attendance, and marks.
- Identified the students with the highest and lowest marks.
- Created three bar charts:
  1. Student Marks Comparison
  2. Student Attendance Comparison
  3. Student Study Hours Comparison

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- GitHub

## Key Findings
- Average study hours: 3.7
- Average attendance: 77.3
- Average marks: 65.9
- Highest marks: Student I (96)
- Lowest marks: Student E (35)
